Do you love me?

🩷

💕 Love Chekar

Do You Love Me? is a free, interactive love-prank and proposal experience from the Raxzen ecosystem, created to turn a simple question into a fun, playful, and memorable moment.

Instead of a traditional form or ordinary Yes/No question, the experience adds a playful twist: the "No" button refuses to stay in one place, while the "Yes" option remains available — creating the classic funny interaction that makes the person smile before they answer. 😄

But Raxzen is designed to be more than just a small prank.

The platform focuses on personalization, beautiful presentation, smooth animations, easy sharing, mobile usability, and memorable interactive experiences.

💗 A Simple Question, Made Interactive

The main experience is built around one simple question:

"Do You Love Me?"

The recipient can interact with the available choices, but the playful No-button interaction makes the experience unexpected and entertaining.

When the No button is hovered, touched, or interacted with, it can move to another position instead of behaving like a normal button.

That simple idea turns an ordinary question into a small interactive game.

The main experience uses a combination of Nunito, Cormorant Garamond, and Dancing Script typography to create a playful yet elegant presentation.

The result is intended to feel like a small personalized digital love experience, not simply a webpage.

😂 The Famous "No" Button

The most playful part of the experience is the moving No button.

Instead of simply displaying two static choices, the No button can move around the screen when the user tries to interact with it.

This creates the classic:

"You can choose No… if you can catch it." 😄

It works as a lighthearted prank rather than a serious relationship test.

There is no actual love detection or psychological analysis involved — the experience is purely designed for entertainment and fun.

It is a free interactive love-prank and proposal-style web experience where the user can interact with Yes/No choices.

No. It is purely for entertainment. It cannot actually determine whether someone loves you.

The moving No button is the main prank mechanic. It moves when someone tries to interact with it, creating the humorous experience.

Can I send it to my crush?

Yes. The website is specifically designed to be shared with someone special through a link.

Can I use it for a girlfriend or boyfriend?

Yes. It can be used as a playful romantic interaction for a partner, crush, Valentine, or someone you want to surprise.

Can I customize the experience?

The project supports personalized sharing features such as custom names and messages through its advanced options.

Can I share it through WhatsApp?

Yes. Since the experience is link-based, the generated/shared link can be sent through WhatsApp and other messaging or social platforms.

Does it work on mobile?

Yes. The interface is designed to be responsive and touch-friendly.

Is it free?

Yes. The website is presented as a free interactive experience.

Can I install it like an app?

The project includes PWA configuration, so supported browsers/devices may allow it to be installed as an app-like experience.

Is this only for couples?

No. It can also be used for crushes, friends, Valentine surprises, proposals, jokes, and other playful situations.
